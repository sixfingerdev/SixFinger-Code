ชุดโครงการชุมชนที่สร้างขึ้นบน SixFinger

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ SixFinger ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-sixfinger](https://github.com/awesome-sixfinger/awesome-sixfinger) และ [sixfinger.cafe](https://sixfinger.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
