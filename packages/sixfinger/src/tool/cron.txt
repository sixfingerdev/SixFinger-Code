Use this tool to schedule recurring work: a prompt that runs on its own, with or without you around.

cron_create registers a scheduled task with a name, a schedule, and the prompt to run. Two schedule forms:
- intervals: "every:5m" or "every:2h"
- cron expressions: "0 9 * * 1-5" (minute hour day month weekday, server local time)

Two execution targets:
- session "new" (default): each firing runs in a fresh session — right for self-contained jobs like "summarize open PRs".
- session "existing": fires into the named session — right for work that needs the ongoing conversation context.

While sixfinger is open, due entries fire automatically. With os_scheduled, the entry is also registered with your OS scheduler (Task Scheduler / launchd / systemd) so it fires while sixfinger is closed — the run happens headlessly and the transcript is written to the session database.

Manage with cron_list and cron_delete. Missed runs (sixfinger closed, no OS registration) are reported the next time it starts instead of silently skipped.
