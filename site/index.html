SixFinger Code

Terminalin için yapay zekâ kod ajanı.

Kodunu okur, düzenler, komut çalıştırır. Bilgisayarında çalışır; telefonundan ve siteden izlersin, yönetirsin. Anahtar yok, kurulum tek satır.

curl -fsSL https://code.sixfinger.live/install | sh

macOS ve Linux (x64 / arm64). Windows için WSL. İlk açılışta tarayıcıda giriş yaparsın.

Hızlı ve Derin

Model seçmek yok: iki mod var. Hızlı günlük işler için, Derin zor işler için. Gerisini biz yönetiriz.

Uzaktan kontrol

Bilgisayarındaki oturumu telefonundan izle, mesaj gönder, izinleri onayla, durdur.

Yerel ya da bulut

Oturumun kendi cihazında çalışsın ya da bulutta. Aynı listede, aynı hesapla.

Tarayıcıyla giriş

Jeton yapıştırmak yok. Komut bir kod gösterir, tarayıcıda onaylarsın.

Nasıl kurulur

  1. Terminale kurulum komutunu yapıştır.
  2. sixfinger yaz. Tarayıcı açılır, kodu onayla.
  3. Telefonundan görmek için bilgisayarda sixfinger link çalıştır, sonra chat.sixfinger.live → Code → Cihazlarım.
sixfinger login     # giriş / sign in
sixfinger link      # uzaktan izleme / remote control
sixfinger logout    # çıkış / sign out
